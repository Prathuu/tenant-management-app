# Tenant Management App

A full-stack SaaS application for managing tenants, rent, utilities, and payments.
Built for landlords, PG owners, and small property managers.

## Monorepo Structure

## Tech Stack
**Frontend**
- Next.js
- TypeScript
- Tailwind CSS

**Backend**
- Node.js / NestJS
- PostgreSQL
- Prisma ORM

**Tooling**
- Turborepo
- GitHub

## Setup

### Install dependencies (from project root)
```bash
pnpm install

### Backend (api)
```bash
cd apps/api
pnpm start

### Frontend (web)
```bash
cd apps/web
pnpm run dev
