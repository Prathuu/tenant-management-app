# Documentation

This folder contains all non-code documentation for the Tenant Management App.
It defines the product scope, features, user flows, and UI references.

The goal of these docs is to keep product decisions, design intent,
and development direction clear and centralized.

## Files Overview

### problem-statement.md
Describes the real-world problem this application solves and why it exists.

### features.md
Lists the core features and capabilities of the application.

### user-flows.md
Defines how users interact with the system for common actions
such as adding tenants, collecting rent, and viewing reports.

### wireframes.md
References planned UI screens and links to design wireframes (Figma).

## How to Use These Docs

- Read **problem-statement.md** to understand *why* the product exists
- Refer to **features.md** before adding or changing functionality
- Use **user-flows.md** to guide UI and API decisions
- Keep **wireframes.md** updated as UI evolves

## Contribution Guidelines

- Update documentation when adding new features
- Keep docs simple and focused
- Avoid duplicating information already present in code
